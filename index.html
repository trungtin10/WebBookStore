Trang giới thiệu dự án WebBookStore

Đây là trang tĩnh dành cho GitHub Pages. Ứng dụng chính của WebBookStore chạy bằng Node.js/Express + EJS, cần backend server để sử dụng đầy đủ tính năng (đăng nhập, giỏ hàng, thanh toán, quản trị...).

Kiến trúc dự án

Backend MVC với lớp Controller / Service / Repository, render view EJS và API riêng cho web + admin.

Công nghệ chính

Node.js, Express, EJS, MySQL, Bootstrap, Service Worker và cấu trúc module hóa theo chức năng.
